# Body Module — Report Template for Specialist

## Структура отчёта для специалиста

### Основные жалобы (complaints)
- Локализация, характер, интенсивность, длительность
- Динамика (усиление/ослабление)

### Функциональные нарушения
- Влияние на повседневную активность (работа, быт, подвижность)
- Ограничения (что перестал/не может делать)

### Телесное напряжение
- Зоны напряжения (голова, шея, плечи, спина, челюсть, живот)
- Связь со стрессовыми ситуациями (если прослеживается)

### Сон и восстановление
- Качество сна
- Время засыпания, пробуждения
- Чувство отдыха после сна

### Образ жизни
- Физическая активность
- Питание
- Курение, алкоголь, кофеин
- Режим работы/отдыха

### Попытки самопомощи
- Что пробовал(а)
- Что помогает
- Что ухудшает

### Красные флаги (red flags)
- Симптомы, требующие медицинской оценки
- Признаки, требующие срочного обращения

### Дифференциальные гипотезы (только для специалиста)
- Мышечно-скелетные
- Неврологические
- Психосоматические / связанные со стрессом
- Требующие дообследования

### Маршрутизация
- Уровень: self_care / medical_consultation / urgent_help
- Срок: today / within_days / within_weeks / routine
- Специалист: general_physician / neurologist / orthopedist / psychologist / emergency_service
- Причины направления
- Временные меры до консультации
