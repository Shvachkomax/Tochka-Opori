# Навигация кабинета специалиста

На каждом автономном экране есть две кнопки:
- «← Назад» возвращает назад только в пределах того же сайта и путей /specialist/. Для прямого перехода без безопасной внутренней истории применяется /specialist.
- «В кабинет специалиста» всегда открывает /specialist.

Маршруты: /specialist/knowledge, /specialist/knowledge/demo, /specialist/my-practice/demo (Preview).
Встроенная «Моя практика» в кабинете врача дополнительной панели не получает.
Проверка: npm run test:specialist-navigation, npm run build.
Ручная приёмка: открыть каждый экран напрямую, проверить «В кабинет»; перейти из кабинета и проверить «Назад»; повторить на iPhone Safari.
Production, API, Supabase и данные пациентов не затрагиваются.
