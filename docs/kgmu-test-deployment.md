## До запуска

1. Отправить подготовленную ветку в GitHub (разрешение пользователя получено).
2. Создать отдельный OpenAI API-проект «Точка Опоры — Казанский ГМУ — Test».
   Добавить его ключ непосредственно в Vercel как OPENAI_API_KEY (серверный Secret).
   Не отправлять ключ в чат и не использовать ключ другого пилота.
3. Согласовать хранилище. Эти изменения НЕ обеспечивают tenant-изоляцию.
   Не подключать общую базу пилотов, считая её изолированной по бренду.
   Вариант без изменения модели доступа — отдельная тестовая база со всеми
   необходимыми миграциями. Создание платной базы в эту подготовку не входит.
4. После выбора базы настроить SUPABASE_URL и SUPABASE_SERVICE_ROLE_KEY,
   отдельные CLIENT_API_SIGNING_SECRET и CONTINUATION_SECRET_PEPPER.
   Проверить остальные обязательные переменные по коду и шаблону окружения.
5. Связать Git с feature/kgmu-test; проверить модели и разрешения нового API-проекта.
6. Развернуть Preview и проверить текст, голос на iPhone Safari, сохранение,
   повторный вход пациента, вход врача, приглашение, запрос специалиста,
   недоступность Health и отсутствие доступа к записям других пилотов.
7. После проверки выпустить deployment нового проекта, подключить домен,
   создать вымышленные тестовые кабинеты и выдать проверенные ссылки и коды.
